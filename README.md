# CP/M-86 v1.1 for PC-9801 series

PC-9801シリーズ向けのCP/M-86 1.1起動用FDイメージです。2DD/2HDの両方を用意しています。DITT.EXEなどのツールでFDに書き込んで実機で利用したり、HxCやGotekのFDDエミュレータなどで利用できます。

動作環境は、2DDまたは2HDのFDDを備えるPC-9801シリーズのノーマルモードです。PC-9801VMとPC-9801RXで動くことを確認しています。

SCSI HDDにも対応しています。ただし、DISK BIOSの新SENSEコマンドを使っているので、それに対応した機種（VM以降？）でなければ、HDDは利用できません。HDDは、セクタ長512バイトで物理フォーマットされている必要があります。物理フォーマット用のコマンドは同梱していませんので、必要ならば別環境で作業してください。

FDDは4台まで、HDD区画は4つまで利用できます。FDDに割り当てられるドライブ文字はA～Dで、HDD区画に割り当てられるのはE～Hです。HDD区画については、SCSI IDと区画番号の小さな順に有効なものを探し、最初の4つにドライブ文字を割り当てます。

また、RS-232Cポートにシリアル端末を接続して利用可能です。通信速度は9600bpsに設定してください。


## 利用上の注意

処理高速化のために、ディスクキャッシュをGVRAM領域に作成して利用しています。そのため、不用意な電源断やディスク交換でファイルの変更内容が失われる恐れがあります。電源を切ったりディスクを交換したりする際には、CCPのプロンプトでCtrl-Cを入力し、再度プロンプトが表示されるまで待つようにしてください（CP/Mのウォームブート時にキャッシュを書き戻します）。

## FDFORMAT.CMD

FDフォーマット用のコマンドです。

```
FDFORMAT B:
```

のようにオプションなしで実行すると、CP/M用のデータディスクとしてディスクを初期化します。CP/Mを起動可能なディスクを作成する場合には、次のように /S オプションを指定してください。

```
FDFORMAT /S B:
```

なお、/L オプションを指定すると低レベルフォーマットのみを実施します。

## HDFORMAT.CMD

HDD区画フォーマット用のコマンドです。対象区画は「SCSI ID:区画番号」で指定します。

```
HDFORMAT 1:3
```

のようにオプションなしで実行すると、CP/M用のデータディスクとしてディスクを初期化します。CP/Mを起動可能なディスクを作成する場合には、次のように /S オプションを指定してください。

```
HDFORMAT /S 1:3
```

/S オプション指定時、対象HDDに「固定ディスク起動メニュープログラム」などのマスターIPLが存在しない場合には、CP/M-86区画をブートするだけの機能を持つ独自のマスターIPLを書き込みます。このマスターIPLにはメニュー機能はなく、区画番号順で最初に見つけたブータブルなCP/M-86区画から、CP/M-86の起動を試みます。


## FDISK.CMD

HDD区画の作成や設定、削除に使うコマンドです。対象HDDはSCSI IDで指定します。

```
HDFORMAT 1
```

起動後の操作は、Linuxのfdiskコマンドに合わせてあります。pで区画情報の表示、nで区画の新規作成、bで起動フラグの設定、dで区画の削除が可能です。変更した区画情報はwでHDDに反映できます。コマンドの終了はqです。区画サイズは、MiB単位で指定します。設定可能な数値は「1」から「512」までです。

## diskdefs

cpmtoolsで利用可能なディスク定義ファイルです。cpmtoolsでCP/Mのイメージファイルを作成、操作する場合に利用します。
